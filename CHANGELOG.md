# Histórico

## 0.3.0 — 19/09/2026

- Nova ferramenta `atualizar_dados_pr`: renova catálogo e CSV, ignorando cache.
- Prazo de cache configurável por `MCP_TCE_CACHE_SECONDS` (0 a 86400 segundos).
- Metadados informam a validade do cache; atualização com falha retorna erro.
- README com instalação, funcionamento, vantagens, limitações e atualização.
- Identificação Booknando Livros, licença MIT e limites de responsabilidade.
- 40 testes locais aprovados; workflow preparado para Python 3.11, 3.12 e 3.13.
